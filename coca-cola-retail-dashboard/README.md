Coca-Cola Retail Analytics Dashboard (Excel)

Overview

This project was developed using Advanced Excel to build an interactive dashboard analyzing retail sales and profitability.

Tools Used
	•	Microsoft Excel
	•	Power Query
	•	Power Pivot
	•	Pivot Tables

Objectives
	•	Analyze sales performance across regions and brands
	•	Evaluate profitability and operating margins
	•	Understand retailer contribution to revenue

Key Insights
	•	Total sales exceeded $12M across multiple regions
	•	Coca-Cola is the leading brand, followed by Dasani and Diet Coke
	•	Major retailers such as Amazon and FizzyCo contribute significantly to revenue
	•	Profit margins showed consistent growth, peaking above 43%

Business Recommendations
	•	Prioritize high-performing brands for inventory and promotions
	•	Strengthen partnerships with top-performing retailers
	•	Optimize pricing and cost structures to improve margins
