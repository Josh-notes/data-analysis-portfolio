**🚨 Payment Risk Intelligence Dashboard**

📌 Project Overview

This project focuses on fraud detection and payment risk analytics using transactional data. The goal is to identify suspicious patterns, monitor fraud trends, and provide actionable insights to improve risk control while maintaining customer experience.

The dashboard was built using Power BI, leveraging strong data modeling, DAX calculations, and business-driven visualization.

🎯 Objectives
Detect fraudulent transactions and monitor fraud patterns
Analyze fraud distribution across regions, devices, and payment methods
Track key risk KPIs for decision-making
Support fraud prevention strategies with data-driven insights

📊 Key KPIs
Total Revenue: 1.04M
Fraud Cases: 4K
Fraud Rate: 47.41%
Average Transaction Value: 119.61
High-Risk Transactions: 4K

📈 **Dashboard Insights**

🔹 Fraud Trend Over Time
Fraud fluctuates across quarters with a noticeable spike in Q3
Suggests potential seasonal or campaign-related fraud activity
🔹 Fraud by Payment Method
Fraud is distributed across Wallet, Bank Transfer, and Card
Indicates no single dominant channel → need for multi-channel risk controls
🔹 Fraud by Region
North America shows the highest fraud cases
Fraud is relatively consistent across regions → global risk exposure
🔹 Device Risk Analysis
Fraud rate is similar across Mobile, Desktop, and Tablet (~0.47–0.48)
Suggests fraud is behavior-driven rather than device-specific
🔹 Risk Factors Breakdown
Strong indicators of fraud include:
High failed attempts
Flagged IP addresses
International transactions

🧠 **Business Recommendations**
Implement real-time fraud detection rules based on failed attempts and IP flags
Introduce multi-factor authentication (MFA) for high-risk transactions
Optimize fraud rules to balance security vs approval rates
Strengthen monitoring for international transactions
Deploy behavioral analytics models for proactive fraud detection
